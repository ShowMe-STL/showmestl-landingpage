# Share preview media

These two files are the Open Graph still and motion for `/place`, `/event`, `/playlist`, and `/profile` links.

- `showme-share.jpg` — `og:image` and the Twitter large-image still. 1200×630. Current cut: color flash-grain high-rise party with the Gateway Arch, logo in the top-left only, no bottom banner.
- `showme-share.mp4` — `og:video`. Silent H.264, 1200×630, about 5 seconds. Same frame as the still.

iMessage can play the video inside the share bubble. That video region is not a link tap target. The still and the page URL are what open the link.

Replace either file in place if the cut changes. Keep the filenames so the meta tags stay the same.
