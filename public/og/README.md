# Share preview media

These two files are the Open Graph still and motion for `/place`, `/event`, `/playlist`, and `/profile` links.

- `showme-share.jpg` — `og:image` and the Twitter large-image still. 1200×630. Current cut: Long Live STL nightclub, cover-cropped edge to edge from the App Store header. A lit “LONG LIVE STL” marquee sits in the crowd, flanked by bottle sparklers, with silver balloons overhead. No letterbox, pillarbox, or bottom banner.
- `showme-share.mp4` — `og:video`. Silent H.264, 1200×630 (1.91:1), about 8 seconds. Same Long Live STL nightclub cut as the still: “LONG LIVE STL” marquee and sparklers, full-bleed with no black bars.

iMessage can play the video inside the share bubble. That video region is not a link tap target. The still and the page URL are what open the link.

Replace either file in place if the cut changes. Keep the filenames so the meta tags stay the same.
